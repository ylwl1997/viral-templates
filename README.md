# Viral Templates（多词一站）

One Astro site: template wall for **Bby Wow AI**, **Coldplay Kiss Cam AI**, and **Ceiling Fan Transition AI**.

- Live: https://viral-templates.pages.dev
- Repo: https://github.com/ylwl1997/viral-templates
- Stack: Astro static · Cloudflare Pages · Waffo/fal stubs · EN + `/zh/` shell

P0 single-keyword sites (`bbywow-ai`, `kisscam-ai`, `ceilingfan-ai`) remain deployed but are **superseded for promotion**.

## Env checklist

| Key | Purpose |
|-----|---------|
| `FAL_KEY` / `FAL_API_KEY` | Real image→video renders |
| `FAL_MODEL` | fal model id |
| `WAFFO_API_KEY` | Payments |
| `WAFFO_MERCHANT_ID` | Payments |
| `WAFFO_WEBHOOK_SECRET` | Webhooks |
| `WAFFO_CHECKOUT_BASE` | Checkout URL base |
| `PUBLIC_GA4_MEASUREMENT_ID` | GA4 |
| `PUBLIC_ADSTERRA_SOCIAL_BAR_ZONE` | Adsterra Social Bar |

No R2 required for P0.
